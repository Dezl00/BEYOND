# Beyond فواتير
نسخة ويب عربية مبنية بـNext.js 16 وNeon وGemini، جاهزة للنشر على Vercel.

## النشر على Vercel
1. استورد مستودع BEYOND، واختر Framework: Next.js وRoot Directory: ./.
2. استورد ملف BEYOND.vercel.env في Environment Variables لبيئة Production.
3. اضغط Deploy. الإعدادات الموجودة في vercel.json تضبط البناء والمنطقة fra1 القريبة من قاعدة Neon.
4. كلمة الدخول هي قيمة APP_PASSWORD داخل ملف ENV. يمكن تغييرها من متغيرات Vercel ثم إعادة النشر.
5. بعد الدخول، أضف قائمة أكوادكم من صفحة «التصنيفات والأكواد»، واضبط صاحب العهدة الافتراضي.

ملف ENV الكامل يُسلّم منفصلًا، ولا يُرفع للمستودع. ملف .env.example يحتوي أسماء المتغيرات فقط.
لا يحتاج الموقع إلى Vercel Blob أو خدمة تخزين إضافية؛ الأصول مؤقتة على جهاز الرفع.

يحتوي ملف ENV أيضًا ENABLE_EXPERIMENTAL_COREPACK=1 لاستخدام إصدار pnpm المحدد في المشروع.

## المتغيرات
- GEMINI_API_KEY: المفتاح الأساسي المستخدم للاستخراج.
- GEMINI_MODEL: الافتراضي gemini-2.5-flash؛ اجتاز اختبار استخراج فاتورة فعلي.
- DATABASE_URL: رابط Neon PostgreSQL.
- APP_PASSWORD: كلمة مرور قوية للدخول إلى النسخة الفردية.
- APP_ENCRYPTION_KEY: مفتاح عشوائي لحماية الجلسات والإعدادات.
- GEMINI_API_KEY_BACKUP_1/2/3: مفاتيح احتياطية للتبديل اليدوي؛ لا يستهلكها التطبيق تلقائيًا.

تم التحقق من Gemini 3.8 Flash، لكنه أعاد 503 بسبب ضغط الخدمة أثناء الاختبار. يمكن اختياره لاحقًا من الإعدادات. Gemini 2.5 Flash استخرج فاتورة الاختبار ببندين وإجمالي 230 وضريبة 30 خلال نحو 3 ثوانٍ.

## الإمكانيات
- رفع متعدد للصور وPDF، والتصوير بالكاميرا.
- حتى 50 فاتورة/صفحة في الدفعة، و25 MB للملف الأصلي. كل صفحة PDF تمثل فاتورة مستقلة.
- استخراج كل بند في صف مع رقم الفاتورة والتاريخ والمورد والرقم الضريبي وصاحب العهدة والتصنيف والكود والمبالغ.
- معاينة الأصل بجانب البيانات، وزر «تعديل جماعي» لفتح الحقول، مع تطبيق قيم على البنود المحددة والتراجع.
- الأكواد من قائمة الشركة فقط. الحقول غير الواضحة أو غير المصنفة تظل للمراجعة.
- كشف الاشتباه بالتكرار، وعرض السجل السابق وسبب الاشتباه، مع الاستبعاد أو سبب مكتوب لإعادة التسجيل.
- حفظ مسودات واستكمال الدفعات المحلية، وبحث وفلاتر بحسب التصنيف والشخص والتاريخ.
- تصدير XLSX وPDF مع اختيار الأعمدة وترتيبها وحفظ الاختيار.
- خلفية بيضاء وحقول فاتحة وثلاث درجات أزرق، بدون ظلال أو تدرجات، وتصميم متجاوب.

## الحسابات
المبالغ مفترضة شاملة ضريبة 15%؛ الضريبة = الإجمالي × 15 ÷ 115.
الحسابات الداخلية بالهللات الصحيحة، مع توزيع فرق تقريب ضريبة البنود بحيث يطابق إجمالي ضريبة الفاتورة.
لا يكرر إجمالي الفاتورة داخل مبلغ كل بند.
الاعتماد يتطلب اكتمال الحقول والتصنيف ومطابقة الإجماليات المكتوبة. يمكن حفظ المسودات غير المكتملة.
الذكاء الاصطناعي يقدم اقتراحًا يحتاج مراجعة بشرية.

## الحماية والحفظ
- النسخة الأولى لمستخدم واحد، محمية بكلمة مرور وجلسة مشفرة AES-GCM وHttpOnly وSameSite=Strict لمدة 7 أيام.
- تتطلب جميع خدمات البيانات جلسة صالحة. تغيير APP_PASSWORD أو مفتاح التشفير يبطل جلسات الدخول السابقة.
- المفاتيح لا تدرج في حزمة الواجهة أو تخزين المتصفح المقروء بالبرامج.
- إدخال بديل للمفاتيح داخل الإعدادات يحفظ في Cookie مشفرة مرتبطة بالمستخدم.
- البيانات المستخرجة محفوظة محليًا، وتزامن مع Neon. رقم مراجعة يمنع الاستبدال الصامت عند تعديل نسختين.
- جدول beyond_workspaces بسجل JSONB لكل مستخدم مناسب لحجم التجربة. إدارة الفرق والصلاحيات وفصل الجداول للتوسع مراحل لاحقة.
- الأصول المؤقتة متاحة 24 ساعة على جهاز الرفع فقط. يحجب الموقع الأصل المنتهي وينظف التخزين عند فتحه وأثناء تشغيله. لا يمكن حذف تخزين المتصفح في وقت محدد أثناء إغلاق الموقع.
- أثناء الاستخراج ترسل الصفحة إلى Gemini. الصور الكبيرة وصفحات PDF الكبيرة تُهيأ محليًا قبل الإرسال لتناسب حد جسم طلب Vercel.
- المحفوظات المحلية مرتبطة بالمتصفح والجهاز؛ فعّل المزامنة قبل الانتقال إلى جهاز آخر.
- البيانات التوضيحية منفصلة عن الفواتير الفعلية، وتظهر علامة واضحة عند تصديرها.

## التشغيل
يتطلب Node.js 22.13+ وpnpm 11.25.
- pnpm install
- أضف المتغيرات إلى .env.local
- pnpm dev
- pnpm check
- pnpm test
- pnpm build
- pnpm start

تنسخ عملية التثبيت عامل معاينة PDF إلى public تلقائيًا.
