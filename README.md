# Beyond فواتير
مساحة ويب عربية بـNext.js وNeon وGemini، بصف واحد ووصف عام لكل فاتورة.

## النشر والتشغيل
استورد المستودع في Vercel كـNext.js، واستورد ملف BEYOND.vercel.env في Environment Variables قبل النشر. كلمة الدخول هي APP_PASSWORD.
ملف ENV الكامل منفصل عن المستودع؛ .env.example يحتوي أسماء المتغيرات فقط.
للتشغيل المحلي: Node.js 22.13+ وpnpm 11.25، ثم pnpm install وpnpm dev.
الفحوص: pnpm check وpnpm test وpnpm build.

## البيانات والمعاينة
- الأعمدة: رقم الفاتورة، التاريخ، الوصف العام، التصنيف، الكود، قبل الضريبة، الضريبة، والإجمالي النهائي.
- لا توجد حقول للمورد أو الرقم الضريبي أو صاحب العهدة، ولا أسماء منتجات أو كميات.
- مساحة جديدة فارغة دون بيانات أو تصنيفات تجريبية.
- المعاينة بملء الشاشة؛ الجدول يستخدم كل الارتفاع المتاح دون سقف قصير للتمرير.
- الصور مخفية افتراضيًا، وزر علوي يظهرها بجانب الجدول أو يخفيها ويوسع الجدول.
- لا توجد لوحات مبالغ مقروءة أو ملاحظات أو مجاميع أسفل الجدول والصور.
- التصنيف قابل للتغيير مباشرة من المعاينة ومن سجل الفواتير. زر تعديل جماعي يفتح بقية الحقول.
- الحفظ والاعتماد في الشريط العلوي. الحقول غير المكتملة محددة داخل الجدول؛ الاعتماد يتحقق من اكتمالها وصحة الحسابات.
- الاشتباه في التكرار يعتمد على بصمة الأصل أو رقم الفاتورة والتاريخ والإجمالي؛ يظهر السبب المطلوب داخل صف الفاتورة.
- الرفع المتعدد حتى 50 صفحة/صورة في الدفعة، و25 MB للملف الأصلي. كل صفحة PDF فاتورة مستقلة.
- التصوير بالكاميرا، استكمال المعالجة، البحث والتصفية، واختيار أعمدة Excel وPDF وترتيبها وحفظ الاختيار مدعومة.
- PDF يحافظ على العربية كصور عالية الدقة، والنص فيه غير قابل للبحث.

## المبالغ والضريبة
الاستخراج يقرأ قبل الضريبة والضريبة والنهائي كلًا على حدة. القيم غير المكتوبة تبقى null.
قبل الضريبة 1,000 مع ضريبة 150 ينتج نهائي 1,150. النهائي الشامل 1,150 فقط ينتج ضريبة 150 وصافي 1,000.
لا يعتبر لفظ الإجمالي وحده دليلًا على أن القيمة شاملة الضريبة.
تعديل قبل الضريبة يضيف 15%، وتعديل النهائي يفصل الضريبة مرة واحدة. التصحيح اليدوي يعتمد على القيم المدخلة دون الحاجة إلى تعديل حقول قراءة الأصل الداخلية.
المبالغ تحفظ بالهللات الصحيحة، ولا تتكرر قيمة الفاتورة بسبب تعدد المنتجات.

## حفظ البيانات والترحيل
الصيغة schemaVersion=3. يزيل الترحيل المورد والرقم الضريبي وحقول الأشخاص والمنتجات القديمة من السجلات وأعمدة التصدير، مع حفظ أرقام الفواتير وتواريخها ومبالغها وأصولها.
الفواتير القديمة ذات التصنيفات المتعددة تنتظر اختيار تصنيف عام.
الحفظ محلي مع مزامنة Neon ورقم مراجعة يمنع استبدال تعديل متزامن. ترحيل Neon يتم ذريًا عند قراءة البيانات.
الأصول متاحة على جهاز الرفع 24 ساعة، وتُحجب بعد انتهاء المدة ويُنظف التخزين أثناء تشغيل الموقع أو عند فتحه.

## المتغيرات وGemini
GEMINI_API_KEYS وGEMINI_MODEL وDATABASE_URL وAPP_PASSWORD وAPP_ENCRYPTION_KEY وENABLE_EXPERIMENTAL_COREPACK=1.
كل المفاتيح في متغير واحد: GEMINI_API_KEYS=key1,key2,key3,key4
الافتراضي gemini-2.5-flash، ويمكن تغيير النموذج في الإعدادات.
عند 429 يجرب المفتاح التالي تلقائيًا لنفس الفاتورة مرة واحدة لكل مفتاح، ويستمر بالمفتاح الذي نجح. يحترم Retry-After وRetryInfo ويؤجل المفاتيح المستنفدة داخل نسخة الخادم النشطة.
إذا نفدت الحصة للجميع تظهر رسالة مع وقت الانتظار وتظل الفاتورة متاحة لإعادة المحاولة. لا يتبدل المفتاح بسبب خطأ ملف أو نموذج أو صلاحية.
تظل متغيرات المفاتيح القديمة مدعومة أثناء الترقية، لكن GEMINI_API_KEYS له الأولوية. ويمكن إدخال قائمة بديلة صراحة من الإعدادات.
حدود Gemini تخص مشروع Google؛ مفاتيح نفس المشروع تشترك في الحصة: https://ai.google.dev/gemini-api/docs/rate-limits

## الحماية والتحقق
نسخة فردية بكلمة مرور وجلسة AES-GCM وHttpOnly وSameSite=Strict. خدمات البيانات تتحقق من الدخول، والطلبات المعدلة تتحقق من المصدر.
المفاتيح تبقى على الخادم، والبدائل المدخلة تحفظ في Cookie مشفرة. لا ترفع ENV إلى GitHub.
الاختبارات تشمل الحسابات والترحيل والتصدير وحذف الحقول، التبديل التلقائي للمفاتيح والمهلة، وإتاحة التصنيف في المعاينة دون فتح التعديل.
فحوص المعاينة تشمل HTML المولّد؛ لم يكتمل فحص بصري داخل متصفح.
